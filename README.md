# Ikejimba Age Grade Association — "Aku Ruo Ulo" website

## What's in this package
- `index.html` — the complete site (single file, works offline except the three.js library, see below)
- `assets/ikejimba_logo.png` — your original logo
- `docs/REVIEW.md` — honest review, ratings and roadmap
- `docs/PROMPTS.md` — ready-to-use prompt scripts for enhancement, evolution, content management and additions
- `docs/CONTENT-GUIDE.md` — how to edit text, events, gallery and SEO by hand
- `docs/original-index-before-upgrade.html` — your original file, untouched

## How to run
Open `index.html` in a browser, or upload it to any web host as `index.html`.

## External dependency
Slide 2 loads three.js (r128) from cdnjs.cloudflare.com. If it can't load, the site automatically shows the CSS doorway instead.
